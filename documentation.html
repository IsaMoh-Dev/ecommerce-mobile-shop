📋 1. user — የተጠቃሚዎች ሰንጠረዥ

ሁሉም ተጠቃሚዎች (ደንበኞች፣ ሻጮች፣ አስተዳዳሪዎች) የሚቀመጡበት።

Column Type Description
user_idINT (PK)የተጠቃሚ መለያ ቁጥር
first_nameVARCHAR(100)የመጀመሪያ ስም
last_nameVARCHAR(100)የአባት ስም
emailVARCHAR(255)ኢሜይል (UNIQUE)
passwordVARCHAR(255)የተመሰጠረ የይለፍ ቃል (bcrypt)
phoneVARCHAR(30)ስልክ ቁጥር
roleENUMcustomer | seller | admin | superadmin
register_dateDATETIMEየተመዘገበበት ቀን

📱 2. product — የስልኮች ሰንጠረዥ

ሁሉም ስልኮች እና መግለጫዎቻቸው።

Column Type Description
item_idINT (PK)የምርት መለያ
item_brandVARCHAR(200)ብራንድ (Samsung, Apple...)
item_nameVARCHAR(255)የስልክ ስም
item_priceDOUBLE(10,2)ዋጋ (USD)
item_old_priceDOUBLE(10,2)የቀድሞ ዋጋ (ለቅናሽ)
item_imageVARCHAR(255)የመጀመሪያ ምስል
item_stockINTበመጋዘን ያለ ብዛት
item_ramVARCHAR(50)RAM (8GB, 12GB...)
item_storageVARCHAR(50)Storage (128GB, 256GB...)
item_featuredTINYINT(1)በመነሻ ገጽ ላይ ይታይ? (0/1)
item_onsaleTINYINT(1)በቅናሽ ላይ ነው? (0/1)

  1. functions.php — በሁሉም ገጾች የሚጠራ። ዳታቤዝ ግንኙነት እና global objects ይፈጥራል።
